# Local Application Dependencies

This directory is the application-local dependency area for offline/self-contained releases.

## Layout

```text
dependency/
├── requirements.txt
├── requirements-lock.txt
├── WHEELS_SHA256SUMS.txt        # generated in release bundles
└── wheels/                      # generated in release bundles
    ├── Flask-...
    ├── cryptography-...
    ├── openpyxl-...
    ├── xlrd-...
    ├── xlwt-...
    ├── PyMuPDF-...
    ├── python_docx-...
    ├── gunicorn-...
    └── all required transitive dependency wheels
```

`requirements.txt` contains the direct application dependencies. `requirements-lock.txt` contains the complete direct + transitive runtime dependency chain.

The actual Python wheel files are platform/Python specific, so they are generated by `scripts/build_offline_bundle.sh` for the target Ubuntu/Python/architecture combination and placed under `dependency/wheels/` in the resulting offline release.

Production installation uses only these local wheel files with `PIP_NO_INDEX=1`, `--no-index`, and `--find-links=dependency/wheels`. No Python package download is required on the target server.
